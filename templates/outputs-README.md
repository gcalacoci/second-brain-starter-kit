# Outputs — Finished Deliverables

Store finished briefings, reports, and summaries generated by agents.

## Structure

- `briefings/` — Research briefings, medium formality
- `reports/` — Formal reports
- `summaries/` — Quick one-pagers

## Naming

`YYYY-MM-DD-<topic>-briefing.md`

## Examples

- `briefings/2026-10-13-ai-second-brain-briefing.md`
- `reports/2026-10-01-q3-product-review.md`
- `summaries/llm-wiki-pattern-summary.md`
